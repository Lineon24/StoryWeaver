# StoryWeaver

캐릭터, 관계, 세계관, 필연을 조회하는 LangChain 도구를 이용해 설정에 일관된 장면을 생성하는 창작 워크스페이스입니다.

## 핵심 기능

- 캐릭터 프로필을 추가·삭제하고 브라우저에 저장
- 기존 데이터를 덮어쓰지 않고 스파이더맨 주요 인물 8명을 선택적으로 추가
- 이름 없는 시민·경찰·경비원 같은 엑스트라는 장면 안에서만 사용하고 설정집에는 저장하지 않음
- 좌우 설정 사이드바를 접어 대본 작업 영역 확장
- 세계관의 시대, 역사, 규칙, 세력 관리
- 죽음·도달·만남·이별·폭로와 같은 필연 및 성립 조건 추가·삭제
- LangChain 에이전트가 캐릭터, 관계, 세계관, 필연 도구를 호출
- 작가와 설정 검수 에이전트에 공통 LangChain 실행 안정화 미들웨어 적용
- 일시적인 모델 오류 자동 재시도, 실행 시간 기록, 구조화 출력 재검증
- 실제 역사 기반 작품에서는 Wikipedia 역사 검색 도구를 선택적으로 호출
- 구조화된 대사, 행동, 감정, 숨은 의도 생성
- 장면 1, 2, 3을 순서대로 추가하고 장면별 입력과 결과 저장
- 새 장면 생성 시 앞선 모든 장면을 LangChain 도구로 조회해 연속성 유지
- 보통 또는 긴 대사 분량 선택과 완성 장면 통합 대본 출력
- 설정 일관성 검사와 필연 수렴도 반영
- API 키가 없으면 명확한 설정 오류를 표시하고 생성 요청을 중단

## 실행

```bash
npm install
cp .env.example .env.local
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다.

실제 AI 생성을 위해 `.env.local`의 `OPENAI_API_KEY`를 설정해야 합니다.

## LangChain 도구

- `get_character_profile`
- `get_relationship_state`
- `search_world_lore`
- `get_inevitabilities`
- `get_previous_scenes`
- `search_historical_context`
- 생성 후 `check_continuity` 단계

작품 내부 설정은 외부 역사 자료보다 항상 우선하도록 프롬프트에 명시되어 있습니다.

## LangChain 미들웨어

두 에이전트는 동일한 안정화 계층을 사용합니다. 모델 호출이 일시적인 네트워크 오류나 요청 제한으로 실패하면 한 번 자동 재시도하고, 처리 시간과 모델 호출 횟수를 도구 추적에 기록합니다. 구조화 출력이 스키마와 맞지 않으면 전체 에이전트 실행을 한 번 더 수행하며, 최종 실패 시 내부 오류 대신 사용자용 메시지를 반환합니다.
